# Context

## Requirements

- Add a complete open-source license at the repository root for the WebMCP Challenge submission.
- Make the deployed Flockdoc URL prominent in the README.
- Preserve the existing application and documentation structure.
- Verify, commit, and push the changes to `origin/main`.

## Repository

- React and TypeScript application built with Vite.
- Existing validation commands are `npm test` and `npm run build`.
- The repository is public at `github.com/jykim16/flockfly-docs`.

## Decision

Use the standard MIT License with the repository owner's configured name and the current year. Add the live URL directly below the README introduction so judges can find it without reading deployment instructions.
